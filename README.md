# MPCE Insight360

AI-Powered Household Expenditure Intelligence System for predicting Monthly Per Capita Expenditure and analyzing rural-urban consumption patterns.

## Project Overview

MPCE Insight360 is a Streamlit-based AI/ML dashboard that predicts Monthly Per Capita Expenditure using machine learning and provides household expenditure analytics.

## Features

- MPCE Prediction using ML
- Rural vs Urban Dashboard
- State-wise MPCE Analysis
- Expense Category Analysis
- Household Segmentation
- Anomaly Detection
- Model Comparison
- Explainable AI using Feature Importance
- Policy Insight Generator
- PDF Report Generator

## Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Plotly
- ReportLab
- Joblib
